How to use

  1. Pick a robot above (or tap it on the map, or press 0–9).
  2. Tap any free cell: the robot drives there. Everyone else replans around it.
  3. Switch to Tap = place robot to put it somewhere else first.
  4. Switch the planner to Independent A* to see what happens without coordination.

How it works

Every tap reruns the project's C++ planner, compiled to WebAssembly, on your device. Prioritized planning plans robots one by one with space-time A*; each robot avoids the ones planned before it, including robots parked on their goals. It is fast but not optimal, and it can fail on a solvable layout. When it does, the page keeps the old plan and tells you which robot got stuck. Conflict-Based Search (milestone M4) will be optimal.

Planner: the project's C++17 code compiled to WebAssembly (web/build_wasm.sh). It runs in your browser; nothing is sent anywhere.
